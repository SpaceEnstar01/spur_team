# Spur 开发版独立语音智能体设计

## 目标与范围

仅修改 Spur，新增独立的 iOS Debug 语音智能体对话页。Recordings 右上角可手动进入；戒指长按开始录音时立即进入。参考用户提供的圆角卡片视觉及 DreameRing 的语音智能体行为，支持文字与手机/戒指语音输入、AI 文字回复、生成图片，以及目的地自动填好的高德打车跳转。不替换 Spur 现有 AI Assistant 卡片流程，不修改 DreameRing 仓库。

本次“仅供开发版使用”的决定覆盖先前“Release/TestFlight 直接可用”要求。新入口和依赖密钥的能力仅在 Debug 开放；Release 保持现有功能。所有本次改动仅加入 Git 暂存区，不提交、不推送。

## 页面与交互

- 在 Recordings 页刷新按钮旁新增清晰的 AI 入口，打开独立 Stack 页面，不新增底部 Tab。
- 使用 Spur 品牌风格：暖白背景、留白充足的圆角卡片、克制的强调色、清晰可读的中英文排版，并跟随现有 `APP_LANGUAGE`，适配安全区和键盘。参考图用于布局与质感参考，不照搬无关控件或图片。
- 页面包含返回、连接/录音状态、可滚动对话、文字输入框和手机麦克风。结果按类型展示文字、真实生成的图片卡片或打车操作卡片；不以装饰图冒充 AI 结果。
- 戒指任务显示“录音中 → 同步中 → 转写中 → 回复中”。失败时保留已完成的内容和具体错误，只重试失败阶段；不宣称已经叫车成功。
- 对话及任务摘要存于本机，重进页面可看到历史；限制历史数量，清空须二次确认。保存图片 URL 或本地缓存，不保存密钥。

## 戒指触发与任务归属

- 接入 iOS RingSDK `touchReq.listeningTouchEvent`，将 `0x0103` 长按事件传给 JS。仅 App 位于前台时即时导航；后台和锁屏时不强行弹页。
- 部分固件可能不上报触控事件，按 DreameRing 的兼容策略，在进入“录音中”状态时创建临时任务并跳页；同一次录音的触控与状态信号必须去重。
- 新控制器独立于页面持有任务。继续由现有自动同步模块统一执行同步；新控制器观察完成事件，并只匹配本次开始后新到达的文件，绝不回退使用旧文件或“最新文件”。多次任务排队处理，不相互覆盖。
- 被新语音智能体认领的短录音不得再次出现在原有 AI Assistant 卡片队列；没有本次触发信号的普通短录音仍走原有队列。
- 兼容策略误触发的普通长录音不送入新智能体；同步后确认其归属 Recordings，并在新页面说明。由于开始时无法确定录音时长，这类固件可能短暂误跳页，这是已接受的限制。

## 智能体与外部操作

- 新建 Spur 专用语音智能体服务/控制器，与现有 `AgentFlowScreen`、卡片存储及 `/api/chat` 调用分开。移植 DreameRing Debug 语音策略，但两个仓库运行时不互相依赖。
- 普通文字回复使用 DreameRing 同款 SiliconFlow Ling Flash 语音模型配置。手机麦克风走 Spur 既有录音/转写能力；戒指使用同步到手机的音频。回复在页面增量显示；离开页面或 App 转后台时可取消请求。
- 明确的生图请求调用 Spur 已验证可用的云端图片接口，展示图片及简短说明，并处理加载、失败与重试；普通文字问题不生图。
- 明确的打车请求先确定性地提取非空目的地，再复用 DreameRing 的高德 MCP 地理解析和 `maps_schema_take_taxi` 流程。校验目的地与 `amapuri://drive/takeTaxi` URI 后唤起高德，目的地应已填好。用户在高德内确认上车点、车型和订单；缺目的地、解析失败或唤起失败时显示可重试错误，不以未填目的地的页面冒充成功。
- 其他外部操作在没有真实、经验证的集成前仅能文字回答，不得声称已预订或购买。

## Debug 密钥与 Release 行为

- SiliconFlow 语音模型 Key 与高德 Web 服务 Key 放在 Spur 本机、被 Git 忽略的 Debug 配置中。暂存的示例/模板只有变量名和配置说明，没有密钥值。原生桥接仅在 `#if DEBUG` 导出密钥；Release 返回空值，不显示新入口，也不自动导航。
- 可以从用户已有的 DreameRing Debug 配置在本机复制密钥，但不得在日志、工具输出、源码差异、测试或 Git 暂存区显示。Debug 安装包的密钥仍可被提取，只适合可信开发测试人员。
- 转写和图片复用 Spur 已上线云端服务；本次不新增生产密钥或服务器部署。未来若要在 Release 开放本功能，需另行设计并部署服务端密钥方案。

## 失败处理与验证

- 请求设置超时与取消，任务串行处理，错误按阶段展示。重复 BLE 状态不得重复导航。外部跳转前严格校验目的地、坐标和 URI 字段。
- 测试长按/状态去重、前台限制、新文件关联、普通录音归属、请求路由、目的地解析与 URI 校验、生图结果、阶段重试和 Release 隐藏。验证 TypeScript、iOS Debug 构建及连接的真机戒指行为；无法由设备验证的部分明确报告。
- 保留工作区已有改动，只暂存本任务自己的文件或变更块；不提交、不推送。
